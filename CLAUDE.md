## Solo para Claude Code

- Al empezar en una rama que ya tiene PR: `/retomar`. Al acabar o si se acaba el cupo: `/relevo`.

- Este repo no tiene `.claude/settings.json` ni hooks: nada te avisa si cierras con trabajo sin subir. Haz el relevo a mano.
